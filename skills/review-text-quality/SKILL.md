# Review text quality

1. Name the reader and the task the text promises they can finish. Follow its actual reading order. In a skill, compare the selection description with the procedure, then locate its inputs, decisions and expected output. In a document or reply, locate the answer or first usable action.
2. Check each consequential ambiguity with two plausible readings of the same words. Show where they change the action or result. Look for missing conditions, unclear references, inconsistent terms, buried exceptions and wording that turns a possibility into a requirement. Compare with the supplied authority. Where it leaves the choice open, name the missing decision.
3. Try removing or moving a passage. Flag it when it duplicates a fact without serving another reader, obscures a decision or places a prerequisite after the step that needs it. Preserve definitions, exact literals, uncertainty and exceptions. Length alone does not establish a defect.
4. Return findings in the requested channel, highest impact first. Locate the passage, state the reader consequence and give the smallest supported correction. Combine repeated instances of the same cause. If the text works, say which reader task you checked. Apply edits only when the assignment requests them.
