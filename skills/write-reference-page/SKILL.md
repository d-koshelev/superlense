# Write a reference page

1. Identify what the reader will look up, the question they need to answer and the applicable version. For an update, find the maintained entry and any supported versions it already covers.
2. Check each answer against the applicable release, implementation or approved definition. A value seen in one example establishes that observation. Verify a default, allowed range or general rule separately. Distinguish a proposal or local override from the released value. If the implementation conflicts with an approved requirement, identify both.
3. Lead with the term or setting and its meaning. Include units, defaults, allowed values, exceptions or examples where they change the answer. Preserve supported differences between versions. State which requested facts the sources leave open.
4. Try answering the reader's lookup from the finished entry, including a relevant exception. Deliver the entry and any requested companion text in their assigned places. For an authorized in-place change, correct in-scope examples or links that give a conflicting answer. For a draft or comments, identify those corrections in the requested output.
