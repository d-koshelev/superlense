# Portability

Run packages use relative paths, JSON, HTML, PNG, and UTF-8 text. Core operation needs Python, Git, and Chromium. A portability campaign records provider/agent identity, versions, unavailable isolation, comparable task/lens hashes, time budget, and results.

Another provider is optional. If unavailable, the result is `NOT_RUN`, never simulated. Processes under the same Linux user are not cryptographically isolated.
