# Lens Catalog index

- Canonical registry: `LENS_CATALOG.json`
- Module packages: `modules/<lens_id>/<version>/`
- Lens Sets: `sets/<set_id>/<version>/`
- Dependency/incompatibility graph: `DEPENDENCY_GRAPH.json`
- Release authority: `../releases/LENS_RELEASE_REGISTRY.json`

Catalog entries link to immutable package digests and evidence. Prototype presence is not release status.
