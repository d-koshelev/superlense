# Component Lens Gate Specification v1

## Rule

Before a new Copilot component is built:

```text
Component Request
-> Component Behavior Decomposition
-> Lens Requirement Matrix
-> Lens Catalog Resolution
-> Missing Lens Orders
-> Foundry/Test Lab
-> Validated Lens Set
-> Component Gate
-> implementation
```

## Examples

### Overlay component

Required Lens Set may include:

```text
Canonical State Projection
Read-Only Boundary
Metric Integrity
Operator Attention
Planning Action Request
Recovery
```

### Knowledge ingestion component

Required Lens Set may include:

```text
Evidence Classification
Duplicate/Conflict Detection
Privacy Boundary
Promotion Gate
Provenance Report
```

### Scientific research component

Required Lens Set may include:

```text
Source Quality
Epistemic Separation
Hypothesis Control
Decision Preparation
Model/Experiment Verification
```
