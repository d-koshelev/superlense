# Web Interface Design Core 1.1 rationale

This version adds four focused decisions: action ownership, causal consistency
between state language and action effect, navigation taxonomy/reachability,
and primary-work identity visibility. The mandatory rule-defect workflow fixes
reusable rules before a later production-interface mission.

The package reuses the existing Catalog, conditional route, schemas, runtime
loader, validator, test framework, and operator override boundary. It creates
no parallel Lens framework, semantic classifier, UI state, or production UI
mutation.
