# Human Attention Budget — Knowledge Note

## Boundary

Protect limited human attention and working memory from competing demands.

This note explains the contract; it is not loaded into the default runtime
context and it does not constitute an independently validated general fact.

## Interpretation

Attention is spent whenever the person must notice, interpret, decide, or reconstruct context. Compact statistics are useful only when the detail remains reachable.

## Practical signals

- Trigger: Any work with multiple surfaces, alerts, decisions, details, or context switches.
- Expected effect dimensions: Focus, Operator Burden, Continuity
- Primary aberration risk: overcompression or missed situational detail

## Examples

- Positive: apply the compact rules only when their inputs and trigger are
  present, then return the required output without naming the Lens to the user.
- Negative: MULTIPLE_EQUAL_FOCI.
- Uncertain: preserve the unknown rather than inventing a premise or status.

## Evidence boundary

The operator-supplied package defines this contract. Local P1 validation can
prove structure, routing, and deterministic fixture behavior; real human and
cross-provider effects remain unavailable.
