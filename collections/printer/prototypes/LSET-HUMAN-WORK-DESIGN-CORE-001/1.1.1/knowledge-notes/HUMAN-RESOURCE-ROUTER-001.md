# Human Resource Router — Knowledge Note

## Boundary

Assign work to the human, Copilot, or execution agent without transferring human decisions to machines.

This note explains the contract; it is not loaded into the default runtime
context and it does not constitute an independently validated general fact.

## Interpretation

Copilot coordinates and synthesizes; it is not a hidden executor. An executor owns no canonical authority and returns evidence to the coordinating flow.

## Practical signals

- Trigger: Task decomposition, delegation, execution planning, and handoff.
- Expected effect dimensions: Coordination, Operator Burden, Boundary Compliance
- Primary aberration risk: role fragmentation or unclear accountability

## Examples

- Positive: apply the compact rules only when their inputs and trigger are
  present, then return the required output without naming the Lens to the user.
- Negative: MACHINE_APPROPRIATES_DECISION.
- Uncertain: preserve the unknown rather than inventing a premise or status.

## Evidence boundary

The operator-supplied package defines this contract. Local P1 validation can
prove structure, routing, and deterministic fixture behavior; real human and
cross-provider effects remain unavailable.
