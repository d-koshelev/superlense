# Design Stop and Review Gate

Stop meaningful design work when the proposed direction cannot be clearly connected to helping a specific user perform a specific primary task.

This removable Layer 1 module cannot override Layer 0 guardrails, operator
authority, tool permissions, domain boundaries, or project state. Its compact
runtime contract is registered in
`printer/prototypes/LSET-HUMAN-WORK-DESIGN-CORE-001/1.1.1/LENS_RUNTIME_CONTRACTS.json`.
