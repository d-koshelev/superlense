# Output contract

Required output:

- `design_direction_status`
- `primary_work`
- `detected_problem`
- `why_current_direction_is_unsafe`
- `preserve`
- `required_correction`
- `deferred`
- `operator_override_or_none`

Material interventions are visible only for an error, alignment mismatch,
operator decision, important risk, or result that would otherwise mislead.
