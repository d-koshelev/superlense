# Website builder lens kit

Use these text modules to take a website from its first brief to an implementation handoff. Start with the intake form in [TEMPLATES](TEMPLATES), then turn the answers into a project baseline. Record a design decision and give an implementation agent the relevant page requirements and acceptance checks.

[LENSES](LENSES) contains the role instructions. [SCHEMAS](SCHEMAS) describes the records passed between roles. [EXAMPLES](EXAMPLES) includes a fictional agency brief. Load only the modules needed for the task. The reusable edition uses a generic operator role throughout.

The complete text kit, including its MIT license, is available in [website-builder.zip](../website-builder.zip).
